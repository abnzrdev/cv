# Software & AI Portfolio / CV

Personal portfolio and printable CV for Abenezer Alemayehu Lemma.

**Website:** https://abnzrdev.github.io/cv/

**Site source:** [gh-pages](https://github.com/abnzrdev/cv/tree/gh-pages), plain HTML and CSS. GitHub Pages publishes from that branch at the repository root. The separate KBTU landing page remains at /kbtu/.

Professional contributions, selected projects, current learning, and contact information. The responsive homepage follows the approved Figma design; `/now/` contains the learning journal. Use the browser's Print command for the printable layout.

To preview, serve the site checkout with any static HTTP server; no build or package installation is required.

Screenshot provenance and missing image paths are documented in images/projects/README.md on the site branch.

Checks: `node --test tests/*.test.cjs` and `node --check intro.js`. There is no compilation, lint, or TypeScript configuration. Local fonts include their OFL licenses. Figma icons and waveform are stored in `images/figma/`; profile photos use the real `abnzrdev` GitHub avatar.

Presentation refined with [Unslop](https://github.com/heydamir/unslop) by Damir Sokolovsky (CC BY 4.0).
